BIZZY ADMIN — локальная админка
===============================

ЗАПУСК
  Двойной клик по start_admin.bat в корне проекта (bizzy_app\).
  Откроется браузер http://localhost:8787 — войдите логином/паролем
  администратора из admin_config.txt.
  Остановка: закрыть окно консоли или нажать в нём Ctrl+C.

НАСТРОЙКА (один раз)
  1. Скопируйте admin_config.example.txt -> admin_config.txt
  2. Впишите три строки:
       строка 1: логин администратора (любой)
       строка 2: пароль администратора (любой)
       строка 3: service_role ключ Supabase —
                 supabase.com -> ваш проект -> Project Settings
                 -> API -> "service_role" (secret)
  3. Сохраните. Файл в .gitignore — на GitHub не уйдёт.

ВАЖНО
  * Пароль в файле не должен содержать символов % & ^ " < > |
    (ограничение .bat) — используйте буквы и цифры.
  * Service_role ключ даёт ПОЛНЫЙ доступ к базе.
    Не публикуйте и не отправляйте никому.
  * Админка запускается только локально (localhost:8787).

ФУНКЦИИ
  * Список всех пользователей: клиенты, мастера, салоны — поиск и фильтры.
  * Смена логина (это и auth-email логина).
  * Смена пароля пользователю (старый не виден — только новый).
  * Блокировка / разблокировка аккаунта.
  * Удаление аккаунта (auth + профиль + карточка).
  * Просмотр отзывов (клиенты -> на мастеров, мастера -> на клиентов)
    и удаление отдельных отзывов.
